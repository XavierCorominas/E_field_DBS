**Deep Brain Stimulation Electrode Monitoring of TMS/tCS/tES-Induced Electric Fields**

This repository provides code for estimating the effects of external stimulation techniques, such as transcranial electric stimulation (tES), transcranial magnetic stimulation (TMS), or focused ultrasound (FUS), on implanted deep brain stimulation (DBS) electrodes in the subject’s native space.

Accurate estimation of the electric field or acoustic pressure at electrode contacts is critical for both safety and data integrity. It helps prevent misinterpreting direct electrode polarization caused by exogenous fields as genuine neuronal responses.
